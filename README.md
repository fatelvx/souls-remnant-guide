# Soul's Remnant 攻略站

玩家自製的 Soul's Remnant 攻略網頁：輸入等級找練功地圖、精華掉落表、拍賣場規則、元素效果、染色心得。

## 更新資料

1. 原始資料放在 `data/raw/`（從 [Soul's Remnant Wiki](https://soulsremnant.wiki.gg/) 整理）
2. 怪物中文名在 `data/names-zh.json`，知道官方譯名可以直接改
3. 執行 `node build.mjs` 產生 `data/site.json`
4. 推上 GitHub，Pages 會自動更新

## 本機預覽

```bash
npx serve .
```
